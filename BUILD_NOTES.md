# Build notes

This is a Django-based working starter for the Loqelo pre-launch site. It stores valid waitlist submissions in the configured database and provides a Django Admin interface.

Included in this source bundle: website source, client logo/fonts/photos/screenshots used by the page, database migration, setup instructions and admin CSV export.

Not included/configured yet: production hosting/deployment, the client's standalone promo video (none was present as a video file in the supplied assets), a full-page translation system, outbound email automation/marketing platform, production spam rate-limiting/CAPTCHA, and a live GA4 property ID. These require client choices, credentials or additional implementation before public launch.
